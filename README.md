# Student Grade Calculator

A simple beginner-level Python project that calculates a student's total marks, average, grade, and pass/fail result.

## Features
- Accepts a student's name
- Accepts marks for any number of subjects
- Validates marks (must be between 0 and 100)
- Calculates total and average
- Assigns a letter grade
- Displays Pass if every subject mark is at least 35; otherwise displays Fail

## Grade Criteria

| Average | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| Below 50 | F |

## Requirements
- Python 3

No external libraries are required.

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

On some Windows systems, use:

```bash
py main.py
```

## Example

Enter student name: Arun
